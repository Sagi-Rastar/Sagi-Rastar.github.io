1 心心念念的自动化部署

  • _config

可以，总算是可以用了。

先不说移动端了吧，现在 pc 端以后换环境应该直接拉 hexo 源代码的这个仓库下来就可以开写了。

参考了一下这篇博客 去重新把写随笔这边用的博客框架弄了一下，现在应该可以提交 md 文件之后用 github action 自动编译以及部署了。

想弄自动部署的起因其实也蛮简单——想在移动端设备上随手就可以写博客。

之前了解到 github action、CI/CD 的时候想尝鲜就在拿 mkdocs 搭的技术笔记那边浅尝了一下 github 的羊毛，发现还蛮好用，移动端只要能推送 md 文件到仓库上之后就可以发布博客，自动化程度还是蛮高的，编译静态网站文件之类的操作也不用太耗时，直接薅 github 羊毛还挺合适。

不过日常随笔这边有一个比较尴尬的点就是 hexo 新建一篇博客的时候还是得用 hexo new 博客名称 （靠）。

其实好像通过 hexo new 这条指令新建的 md 文件也没有添加啥东西，就是自动生成的日期 meta 元素而已。后面可以考虑用 obsidian 的模板插件搞一个跨平台的写作环境。
